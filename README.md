# AI-Sungwoo-Profile

성우전자㈜ 회사소개 대시보드 — 단일 HTML 파일로 완결되는 인터랙티브 회사소개서입니다.

## 사용 방법

`성우전자_회사소개_대시보드.html` 파일을 다운로드해 더블클릭(또는 브라우저로 열기)하면 바로 실행됩니다. 별도 서버나 설치 없이 파일 하나로 동작하며, 모바일/PC 어디서든 동일하게 열립니다.

## 포함 내용

- 회사 개요 (설립·매출·임직원·생산거점 KPI)
- 연혁(History) 타임라인
- 사업 포트폴리오 (호버 인터랙션)
- 연도별 매출 추이 차트
- 글로벌 네트워크 (사업장 사진 + 세계지도)
- 핵심역량 5개 부문 (원본 슬라이드 연결)
- 품질 인증 및 수상
- 주요 고객사 로고 (3D 틸트 효과)
- 공정 영상 3편 (내장 재생)
- 다크모드 토글, 좌측 목차, 인쇄 최적화 등 UX 기능
